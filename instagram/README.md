# STRATA Instagram page

This folder is the public Instagram studio for **STRATA**, the AI Strategy Director.

1. The page opens on a 31-second introduction film: what the app is, the problem it ends, why it is one of a kind, and a try-for-free CTA.
2. Skip or wait — the official `strata.director` profile follows, with highlights, a 12-post grid, reels, and captions ready to publish.
3. Every CTA goes to `try.html`.

```bash
python3 -m http.server 4173 --directory instagram
```

Then open `http://127.0.0.1:4173`.
